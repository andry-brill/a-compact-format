# Noto Sans

The example bundles Noto Sans so Unicode superscript and subscript digits come from one font on every platform.

Source: [Google Fonts — Noto Sans](https://github.com/google/fonts/tree/main/ofl/notosans), `NotoSans[wdth,wght].ttf` (renamed to `NotoSans-VF.ttf`). The unmodified variable font includes all ten superscript and subscript digits, their signs, and Cyrillic labels.
